# Contributor Guide for latex-engineer

## Source of Truth
Edit only `skills/latex-engineer/SKILL.md` and its references in `skills/latex-engineer/references/`. 

## Agent Files
Do NOT edit agent-specific files directly (`.cursor/`, `.windsurf/`, `.clinerules/`, `agents/`, etc.). They are generated and synced from the main skill definition.

## Constraints

- Add large domain knowledge to `references/*.md`.
